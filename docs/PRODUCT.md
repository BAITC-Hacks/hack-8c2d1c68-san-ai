## Поэтапное представление структуры

По указанию пользователя: первый уровень показывается по кругу; начиная с департамента — дерево сверху вниз. Каждый переход загружает только корень и его непосредственных детей, включая сотрудников любого уровня. Интерфейс использует `/api/branch`, с хлебными крошками и страницами больших групп. В демоданные добавлены роли генерального директора и директоров департаментов путём перераспределения существующих сотрудников; общее число осталось 20 000.

Интерфейс занимает высоту окна без прокрутки страницы. Левая структура минимизируется, правая панель деталей скрывается; обе изначально свёрнуты. Основная площадь отдана карте, длинное содержимое прокручивается внутри панелей. На узких экранах панели открываются поверх карты.
