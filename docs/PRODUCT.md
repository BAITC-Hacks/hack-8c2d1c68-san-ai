## Принятые решения

Пользователь поручил инициализировать Next.js с backend/frontend, подключить Sigma.js + Graphology, подобрать БД и заполнить 20 тыс. моковых записей. Реализован этот начальный стенд: 20 000 синтетических сотрудников, 20 департаментов, 200 отделов. PostgreSQL выбран для данных; PGlite позволяет запуск без Docker. Добавлены локальный DOCX-парсер и проверка источников. AI-извлечение и загрузка через UI пока не реализованы. Контракт стенда: [API.md](API.md). Выполненная работа и проверки Document Intelligence: [DOCUMENT_INTELLIGENCE.md](DOCUMENT_INTELLIGENCE.md).
